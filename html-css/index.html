Le guide d'introduction au HTML/CSS

Étudiants de Digital Student, bienvenue sur votre guide d'introduction au HTML/CSS. À la fin de ce guide, vous aurez toutes les clés en main pour créer votre premier site web HTML5 et CSS3.

Pourquoi apprendre HTML/CSS ?

Le HTML et le CSS sont la base de l'internet tel que l'on le connait. Sans HTML et CSS, aucun site internet que tu visites ne ressemblerait à ce que tu vois aujourd'hui.

Complémentaires, HTML définit la structure, le squelette de ton site, tandis que CSS magnifie tout cela grâce à des styles.

Une porte d'entrée obligatoire, si tu veux progresser dans le web et devenir un développeur aguéri, maîtrises d'abord tes fondamentaux !

Les balises de base

Il existe de nombreuses balises pour de nombreux usages en HTML. Il est très important de choisir ses balises consciemment et d'avoir une bonne structure sématique afin de favoriser l'accessibilité et la navigation sur votre site et également le référencement. 

Les balises <h1> à <h6>

Les balises h1 à h6 sont utilisées pour représenter les titres de section. Sur 6 niveaux différents, les balisent correspondent au niveaux différents niveaux de titrage souhaité, en commençant par h1 le plus élevé et h6 le plus faible.


Voici un exemple d'utilisation :

<h1> Titre de niveau 1 <h1>

La balise <p>

La balise <p> sert à définir un paragraphe. Ce bloc structure le texte. Ce sont des éléments de niveau bloc et se ferment automatiquement si un autre élément de niveau bloc est analysé avant la balise de fermeture.


Voici un exemple d'utilisation :

<p> Voici un bloc de texte de type paragraphe. <p>

<p> Ajouter plusieurs blocs de paragraphes permettent de structurer un texte et faciliter l'accessibilité. <p> 

La balise <a>

La balise <a> ou "ancre" créé un hyperlien vers des pages web ou fichiers, adresses e-mail, emplacements dans la même page ou toute autre ressource accessible par une URL. Elle est toujours accompagnée de son attribut href.


Voici un exemple d'utilisation :

<a href="https://mon-lien.com"> Cliquez sur mon lien<a> 

La balise <img>

La balise <img> permet d'intégrer une image dans un document. Elle est accompagnée d'un attribut src qui contient le chemin vers l'image et l'attribut alt obligatoire qui contient un texte de remplacement pour l'image, extrêment utile pour l'accessibilité.


Voici un exemple d'utilisation :

<img src="/chemin/assets/images/mon-image.jpg" alt="Mon image"> 

La balise <ul>

La balise <ul> permet de créer des listes non-ordonnées. A l'intérieur on retrouve souvent la structure :
<ul>
<li> </li>
<li> </li>
</ul>


Voici un exemple d'utilisation :

Liste :
<ul>
<li> Élément 1 </li>
<li> Élément 2 </li>
</ul>

5 Tips & Bonnes pratiques

  • Gardez une bonne structure sémantique
  • Organisez vos fichiers
  • Séparez le HTML du CSS
  • Vérifiez les ouvertures et fermetures de vos balises HTML
  • Validez le code de vos pages sur Validator W3C
